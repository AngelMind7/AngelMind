# Governance and Approval Policy

AngelMind treats approval, policy, and execution as distinct states. A Tier 3 request creates an approval record, records the blocked proposal in the audit ledger, and alerts the owner. Approval decisions carry a timestamp and optional rationale. Neither approval nor rejection causes an action against a target.

Finding states include `discovered`, `triaged`, `candidate`, `reproducing`, `validated`, and `reported`, with terminal alternatives for `invalid`, `duplicate`, and `inconclusive`. Submission is not exposed as an automated dashboard capability. A report remains a human-reviewed draft before it can be submitted through the applicable program process.
