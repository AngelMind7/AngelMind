# Domain 04 — Threat Surface

Blueprint-aligned scope: surface mapping, exposure findings, subdomain and certificate monitoring, cloud exposure and code leakage signals.

## Implemented contract
- Surface data is modeled as observations with provenance.
- Active checks require explicit target scope and authorization.
- Code and secret scanning produce sanitized evidence.
- Certificate and exposure monitoring are non-destructive by default.
- Dark-web references are treated as intelligence records; collection must respect applicable law and provider terms.
